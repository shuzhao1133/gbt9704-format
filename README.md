# gbt9704-format：一键规范政府 Word 文档格式

面向政府十五五规划、工作报告、行业研究报告和一般公文材料的 Word 自动排版工具。依据 GB/T 9704—2012 的适用规则，自动统一页边距、字体字号、标题层级、行距、首行缩进和页码，并检查标点、序号、附件说明及日期格式。
既可以安装为 Claude/Codex Skill，也可以作为独立 Python 命令行工具运行。

- ✅ 不改写正文内容和事实数据，仅统一版式，并规范标点、序号、日期及公文格式字符
- ✅ 明显的序号问题直接修（缺点号补齐、明显跳号自动改号）；拿不准的（重号乱序、大缺口、图表编号）**绝不擅改，只提示**——`--review` 模式产出**批注版**：修复落文 + 每处敏感修复留【已修复】批注 + 待人工项留【检查】批注
- ✅ 封面、目录自动识别保护；标题与清单自动二分（标题顶格、正文缩进）
- ✅ 纯 `python-docx` 实现，**不需要装 Word/WPS**，Mac / Windows / Linux 都能跑
- ✅ 电话、ISSN、英文、小数点、千分位等**全部智能防误伤**（断言测试 125 条全绿）

## 功能清单

### 版式一键统一（GB/T 9704—2012）

1. **页边距**：上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm（A4，版心 156×225mm）
2. **题目自动识别** → 方正小标宋简体二号、不加粗、居中
3. **章级标题**（第X章 / 第X篇 / 前言 / 目录 / 附录 / 参考文献）→ 黑体三号居中，标题内空格保留（"第一章 总则"不会被误删空格）
4. **四级标题体系**：一、黑体 →（一）楷体_GB2312 → 1. 仿宋_GB2312 →（1）仿宋_GB2312，均三号不加粗
5. **正文**：仿宋_GB2312 三号，首行缩进 2 字符（用空格顶缩进的段落自动修正）；**标题顶格**——真标题（一、（一）与"1.优化布局"式短标题）不缩进，"1.《文件》"式清单与连排段按正文缩进（`--indent-headings` 可恢复红头公文式全段左空二字）
5a. **封面与目录保护**：规划/报告书形态（前言、目录、第X章开篇）的封面区除题目外原样不动；Word 自动目录（SDT/TOC 样式）不碰，且置 updateFields 让 Word 打开时自动刷新目录页码
6. **行距**：标题固定 33 磅，正文固定 28 磅
7. **数字与英文**：Times New Roman
8. **页码全自动**（GB/T 9704 第 7.5 条）：宋体四号"— 4 —"两侧一字线、一字线上缘距版心下边缘 7mm、单页码居右空一字、双页码居左空一字、奇偶页不同页脚、Word 页码域自动更新
9. **黑字白底**：清除页面背景色、段落底纹、高亮、彩色文字、下划线（网页粘贴后遗症一键清除）
10. **表格自动调整**：表内字体统一仿宋_GB2312、黑字；字号与表头加粗保留原样

### 文字格式硬伤逐一自动修复（正文 + 表格逐格扫描）

11. **多余空格全删**：段首 / 段尾 / 汉字之间 / 全角空格 / 表格单元格首尾——英文单词间空格智能保留（`WTO members` 不受影响）
12. **半角标点转全角**：`, ; : ? ! ( )` → `，；：？！（）`——小数点 12.5、千分位 1,500、英文缩写不误伤
13. **全角字母数字转半角**：`２０２５` → `2025`
14. **序号写法纠错**：`1、`→`1.`；`（一）、`→`（一）`；`一，`→`一、`；`(1)`→`（1）`
15. **并列书名号 / 引号去顿号**：《通知》、《方案》→《通知》《方案》（GB/T 15834：标号本身即分隔）
16. **发文字号六角括号**：`国发[2024]5号`→`国发〔2024〕5号`——仅匹配"括号+年份+序号+号"，注释 [1] 等不受影响
17. **连接号规范**：年份起止范围半字线改一字线（2023-2025年 → 2023—2025年）——ISSN 1000-1234、电话号码、"中国-东盟"等复合名词一律不动
18. **省略号 / 重复标点**：`...`→`……`；`。。`→`。`
19. **标题末尾句号自动删除**
20. **成文日期规范**（7.3.5.4）：汉字日期转阿拉伯、月日虚位删除、"X月X号"→"X月X日"
21. **发文序号规范**（7.2.5）：〔2024〕第05号 → 〔2024〕5号
22. **百分数范围两端写%**（GB/T 15835）：5～8% → 5%～8%；半角~转全角～
23. **千分位逗号删除**（中文语境）：1,500亿元 → 1500亿元
24. **直双引号自动配对转弯引号**：成对时转""，落单只提示
25. **附件说明格式**（7.3.4）："附件1：xx" → "附件：1.xx"，名称末尾标点删除
26. **空白段落清理**：正文区空段全删（封面、含图片/分页符的保留）
27. **段前段后间距清零**；连接号规范新增全角连字符（`（2026－2030）`→ 一字线）
28. **书名号规范**：`<<通知>>` → 《通知》；单字符省略号 `…` → `……`；括号内外侧任一邻汉字即转全角
29. **表格安全保护**：两表之间的空段保留（防止删除后表格合并）；表题/图题内的分隔空格保留

### 审查模式（v2.1）：修复落文，批注留痕

`--review` 输出**批注版单文件** `原名_GBT9704批注版.docx`：全部自动修复直接落在文中；敏感自动修复（序号补点、跳号改号）各留一条【GB/T9704已修复】批注供核对；机器不敢改的留【GB/T9704检查】批注（署名"GB/T9704格式审查"，文档原有批注完整保留）：

30. **序号缺标点两档处理**：数字+书名号（`23 《零售业态分类》`/`23《零售业态分类》`）**自动补下脚点**；数字+空格+汉字、汉字序数缺顿号（"一 规划范围"）歧义更高只批注（"5 个项目"等量词表述不误报）
31. **序号跳号 / 重号 / 乱序 / 越级**：按章重置计数；**缺口≤2 的明显跳号自动前移改号**（级联，"一、二、四、五"→"一、二、三、四"，每处留【已修复】批注提醒核对交叉引用）；大缺口、重号（含隔位）、乱序只批注——该改号还是补内容，机器无法判断；越级只对真标题提示，并列清单不误报
32. **图表编号检查**：表1/表一体例混用、编号断档乱序（改号涉及正文引用，不擅改）
33. **数字用法审查**（GB/T 15835）：五年规划专名未加引号（裸"十五五"）、世纪年代汉字（"上世纪八十年代"）、约数叠用（"约30家左右"）、发文字号年份缩写（〔24〕5号）
34. **其余人工提示**：题目超一行排梯形/菱形（7.3.1）、附件未另面编排（7.3.7）、引号落单、书名号不配对、文末成文日期编排
35. `--no-layout --review` 组合：版式**只查不改**，字体/字号/行距偏差汇总成批注

## 使用方法

### 方式一：作为 Claude Skill（推荐）

1. 下载本仓库的 [`gbt9704-format.skill`](./gbt9704-format.skill)
2. 在 Claude 桌面版里把 `.skill` 文件拖进对话，点 **保存 skill**（或在 设置 → Skills 中添加）
3. 之后对 Claude 说：**"帮我把这份报告调成公文格式：xxx.docx"** —— 全自动出终稿

Claude Code / opencode 用户：把仓库 clone 到你的 skills 目录即可。

### 方式二：纯命令行（不需要 AI）

```bash
pip3 install python-docx

# 一键统一排版 + 修复全部文字格式硬伤
python3 scripts/format_fix.py 文稿.docx -out 终稿.docx

# 审查模式：输出批注版（修复落文 + 已修复/检查两类批注）
python3 scripts/format_fix.py 文稿.docx --review

# 只修文字格式硬伤，保留文档原有版式
python3 scripts/format_fix.py 文稿.docx -out 终稿.docx --no-layout

# 红头公文式全段缩进（各级标题也左空二字）
python3 scripts/format_fix.py 文稿.docx -out 终稿.docx --indent-headings
```

运行结束会打印分类修改统计（改了多少处空格 / 标点 / 序号）、敏感自动修复清单（补点、改号），以及需要人工处理的提示（如重号乱序）。

跑测试：`python3 tests/test_format_fix.py`（125 条断言，零第三方依赖，只需 python-docx）。

## 字体说明

输出文档引用 **方正小标宋简体、黑体、楷体_GB2312、仿宋_GB2312、宋体、Times New Roman**（楷体/仿宋用 GB2312 版字体名，与 GB/T 9704 原文写法一致）。政府单位的 Windows 电脑与 WPS 普遍自带；本仓库出于版权原因**不分发任何字体文件**。机器缺字体时以宋体代显，只影响本机预览，不影响文件本身的正确性。
